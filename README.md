# WGU CS Course Tracker

This is a Tracker app that allows someone to track their degree plan for WGU Computer Science Bachelor's before they enroll. It also helps them complete courses by leading them to reddit to find information from people who have completed those same courses themselves.

## Who it's for

People planning to enroll into WGU who want to spend as little time as possible.

## How to run it

Download or clone this folder, then open index.html in a web browser (double-click it). It runs entirely in the browser — no server, no install, no internet needed.
